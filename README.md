Twilio SMS integration library implementing the following endpoints:
 1. Inbound message webhook; configure in Twilio interface under "Active Numbers", selecting the target number, and registering remote endpoint under Inbound Message Received textbox; recommend establishing a Twiml backup script for server faults.  Current implementation over-rides the universal auto-reply function to check for communication in the last X months and only reply if the number has no inbound messages within that timeframe.  This implementation provides a more smooth client conversation, reduces reply lag, and eliminates Twilio reputation compliance faults for replying to unsubscribed numbers.
